# StudySearch – Pipeline Operator guide

**Version:** 1.0 (reviewed for platform release v2.17.0)  
**Role:** Pipeline Operator (rank 4)  
**Change control:** CF-247  
**Source:** generated from the Pilot `src/guide/roleGuides.js` and the menu; never edited by hand.

## 1. What this role is for

Keep the data pipeline moving: watch jobs and queues, run and pause them, and send work back to the AI.

## 2. What you can do

- Everything a Curator can.
- Run, pause and resume scheduled jobs; read API usage and services and limits; re-infer a Layer 1 parser.

## 3. What you cannot do

- Activate sources, approve or publish, change settings or manage users (Platform Admin).
