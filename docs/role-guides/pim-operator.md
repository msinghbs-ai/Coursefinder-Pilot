# StudySearch – PIM Operator guide

**Version:** 1.0 (reviewed for platform release v2.16.61)  
**Role:** PIM Operator (rank 5)  
**Change control:** CF-247  
**Source:** generated from the Pilot `src/guide/roleGuides.js` and the menu; never edited by hand.

## 1. What this role is for

Manage records: add and archive providers and courses, approve fee rules, build adapters and publish providers.

## 2. What you can do

- Everything a Pipeline Operator can.
- Add and archive records, approve fee rules, use Adapter builder and the integration queue, publish a provider.

## 3. What you cannot do

- Change settings, models, keys or users; approve destination data; activate a Layer 1 source (Platform Admin).
