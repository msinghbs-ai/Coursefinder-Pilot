# v2.15.410 — Provider descriptions: the right About page

**Date:** 3 November 2026

## What changed

- The description reader reads only the provider's own About page on its main site. News, staff, research and faculty pages are refused.
- Nothing is cut to fit. A description over the length limit, or a cut-off sentence, is held for review.
- The 900-character limit is unchanged. A 1,200 limit is proposed to the Platform Admin.
