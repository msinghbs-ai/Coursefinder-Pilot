# PIM Admin v2.15.410 — The course link fill waits for Layer 4

Date: 3 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

- **Pause threshold is a setting:** Official link: fills before the pause check (50, unchanged value).
