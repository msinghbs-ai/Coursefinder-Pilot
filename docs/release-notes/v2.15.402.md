# PIM Admin v2.15.402 — A course page is linked only when it is proved to be the course's own

Date: 2 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Course page check:** a page is linked to a course only when it is shown to be that course's own page. Refused pages go to Layer 4 › Course link once and are not linked again.
- **Awards within a course:** linked to the parent course page only where that page names the award, or a person recorded it.
- **Shown page:** where a course has several official pages and none is primary, its own page is shown when it passes the check.
- **Monitoring:** Health and Queue watch count what is actually waiting; a daily limit shows as paused.

## Bug fixes

- Graduate Certificates and Diplomas could be linked to their Master's page, or to an older handbook year, and show its fee.
- A false 'course page reading has stopped' alert counted pages of hidden universities.
- AI course matching never paused when idle.
