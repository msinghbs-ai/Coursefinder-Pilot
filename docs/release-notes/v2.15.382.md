# PIM Admin v2.15.382 — Rule 4 retired; every published entry score

Date: 31 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Rule 4, "low agreement, page wins" (StudySearch D3):** retired by the Platform Admin.
  - It stays switched off and can no longer be run.
  - It is marked for removal after the retirement period.
  - Fields whose sources disagree go to Layer 4 review.
  - Its 22 past admissions and their evidence are kept.
- **Website API v2, course detail (StudySearch D4):** `entry.min_scores` lists every admitted entry score exactly as the provider prints it, for example ATAR, IB, GCE A Level and pathway programmes.
  - Each score comes with its words, quote, source and date.
  - `min_score` and `min_score_basis` are unchanged.
  - Developer guide issue 7 describes the new field.
