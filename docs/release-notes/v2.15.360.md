# PIM Admin v2.15.360 — Governed actions: approve operations in the admin UI

Date: 27 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Governed actions** (Platform Admin, Layer 2/3 › Operations): an operation that used to be run as SQL is previewed against the live system and approved here. The preview shows each precondition with its expected and current value, a dry run that is rolled back, and when the approval expires. Approving runs it once, with a reason. Pressing again runs nothing; a refusal or failure changes nothing and says why.
- **First action: close the AER PR A recovery.** It shows the six recovery runs' outcomes, the proposed, active and quarantined entry rows, the cost and the reading scope. On approval it takes RMIT out of the entry-requirements reading scope. It admits nothing: the proposed rows stay in Layer 4 review.
- Consumer API unchanged.

## Bug fixes

- Edit in list: a duration or fee change is saved once. Leaving the cell while it saves no longer saves it a second time.
