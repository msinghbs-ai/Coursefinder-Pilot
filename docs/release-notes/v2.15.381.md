# PIM Admin v2.15.381 — Faster course results for the website and Zoho

Date: 31 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Website API v2 and Zoho course results (StudySearch D6):** each course in a result is built about twice as fast.
  - **Measured in the database:** a median of 536 ms becomes 280 ms for 50 courses.
  - **Responses are byte-identical:** no key, value, order, filter or identifier changes. This was proven on 34 representative searches and 400 courses before release.
- **Consumer API:** the contract is unchanged; the change was approved by the Platform Admin under the consumer API rule.
