# PIM Admin v2.15.374 — Approve except keeps active rows

Date: 30 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Layer 4 › Inbox, entry requirements (decision D4):**
  - Under Approve except, an active row is replaced only when you approve a new row with the same identity.
  - An active row whose new reading you leave out stays active and unchanged, and so does a row the new read does not carry.
  - The excluded row records the active row it would have replaced, and the decision event lists what was replaced and what was kept.
- **Held decisions:** if two approved rows have the same identity, or an approved row is already active elsewhere for the provider, the whole decision is held with nothing changed, and the item stays waiting.
- **Course pages:** on a course page that already has active rows, Approve except is held. Use Approve all rows or Reject instead.
- **Consumer API:** unchanged.

## Fixes

- **Adapter measures** checked its role in a way that never applied, so any signed-in user could read it. It now requires rank 5 or above, as originally intended (decision D6).
