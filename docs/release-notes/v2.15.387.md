# PIM Admin v2.15.387 — Fewer false job failures; admission jobs no longer start together

Date: 1 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Platform health and the weekly scorecard (StudySearch SS-004):** a scheduled run that the scheduler cancelled because the flag unit was pausing that job for idleness, within seconds, now counts as paused, not failed.
  - Every other failure, cancellation or time-out still counts.
- **Scheduled jobs:** the three admission jobs no longer start in the same minute.
  - Admit official page and English stays at minute 0; adapter overwrite moves to minute 3; admit intakes moves to minute 8 of each 10.
  - They write the same rows and had been timing each other out (7 times in 4 days).
  - Commands, frequency, batch sizes and time limits are unchanged.

## Bug fixes

- **Platform health, coverage sweep queues:** a page or provider that had only just become due after a quiet spell was reported as a critical stall ("nothing processed for 341 minutes") until the next check.
  - Waiting is now measured from the later of the last progress and when the oldest waiting item became due.
  - A queue whose items stay waiting still ages and still goes critical.
