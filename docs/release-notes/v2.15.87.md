# PIM Admin v2.15.87 — Layer 4 approvals fixed

Date: 24 Sep 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Approving a tuition fee (single, edited or batch) records the fee; it appears in search and the website API.
- Approve is offered only for proposed fees already marked per year; otherwise use Edit and approve.
- The Edit and approve form has its own pre-filled note; no pop-up.
- The floating "OpenRouter API Key" button is removed; manage the key in Administration > Environment migration.

## Bug / UI fixes

- Approve and Edit and approve for tuition fees previously did nothing.
- Errors appear in the review panel.
- Decision buttons no longer appear twice while editing.
- Items with no proposed fee are no longer labelled "Suggest approve".
