# PIM Admin v2.16.14 — Course descriptions start with the course's own facts; every AI call is recorded as it happens

Date: 16 Nov 2026

Platform Admin, 16 Nov 2026 12:36.

## What's new

- Course descriptions are written with prompt cdesc-source-grounded-v3. It forbids an opening sentence that only introduces the course ("The <course> at <provider> is a ...") and asks for the first sentence to start with a fact the course page prints. In the 48 hours before, most descriptions held by the checks were held for that opening sentence.
- Settings › Settings › Course description and deadline: "rules that earn a second model" decides when a description the first model wrote is asked once more of the next model.
- Two telemetry reports, one by AI service and model tier (calls, tokens, cost, first-pass admission, rescue by the second model, cost per admitted record, spend the ledger did not receive) and one from page discovery to the catalogue (readings, admitted, sent to a person, held, AI waste, yield), feed the telemetry sheet.

## Bug / UI fixes

- Every AI attempt is recorded as soon as it finishes, so a worker call the platform stops part-way no longer loses the cost of the attempts it had already made.
- A course description declined again records the rule version that declined it (cdesc-machine-v2).
- The website and Zoho APIs are unchanged (checked against their baseline before and after the change).
