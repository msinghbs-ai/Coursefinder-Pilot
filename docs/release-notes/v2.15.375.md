# PIM Admin v2.15.375 — Printed grades with no stated scale

Date: 30 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Entry requirements, no stated scale (decision D5):**
  - When a page prints a grade but does not say on what scale, the row keeps the grade exactly as printed, with no numeric value and no scale.
  - In the AER workspace and Catalogue › Entry requirements, a matrix row's scale can be set to **Not stated on the page**. Course-page rows do not offer it.
- **Website API v2 (additive):**
  - Every provider entry-requirement item and every course entry-resolution row now carries `scale_stated`.
  - It is `true` when the page states the scale, `false` when it prints a grade with no scale, and empty when the requirement is case by case.
  - No existing field changed.

## Fixes

- None.
