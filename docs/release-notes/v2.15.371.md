# PIM Admin v2.15.371 — Site re-maps keep proven course pages; Universities list in pages

Date: 30 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Course pages:**
  - A routine re-map of a university's site no longer re-scores, demotes or replaces a course page that the reader has proved with the course's code (CRICOS, NZQA or adapter) or with a manual proof.
  - When pages drop out of the map, only pages the site-map binder bound itself are released.
- **Page identity:** a labelled programme number proves a page for New Zealand courses only.
- **Layer 2/3 › Universities:**
  - The list reads one page at a time, with the filters, search and order applied on the server.
  - Show more reads the next page.
  - Tick every row shown still ticks every matching row.
- **Consumer API:** unchanged.
