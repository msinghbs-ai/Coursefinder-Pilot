# PIM Admin v2.15.81 — Faster Dashboard

Date: 23 Sep 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- The Dashboard and layer status summaries are pre-calculated every 2 minutes, so they open instantly.
- The Dashboard shows when its figures were last updated.

## Bug / UI fixes

- The Dashboard no longer fails to load at busy times.
- Open reviews shows the real number of items waiting in Layer 4 (it previously always showed 0).
- Recent activity includes Layer 4 review decisions.
