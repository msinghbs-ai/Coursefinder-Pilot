# PIM Admin v2.15.494 — Operations by lane, Firecrawl allowance and course description review capacity

Date: 8 Nov 2026

## What's new

- Layer 2/3 Operations shows every automated lane stage by stage: what moved in the last 24 hours, what waits for a person, and what each job did. A green job, a stage transfer and published data are kept apart.
- Models & services > Firecrawl shows the plan allowance, live remaining credits, the last sync, the reserved floor and the room above it, and daily use by group. It is read only and shows credits only.
- Layer 4 Inbox, Course description pill, shows review capacity and a review pack ordered by university, with objective flags on each item. Nothing is decided for you: every admission still needs a person.
- The course search queue no longer says tomorrow's share when the cause is a hold on course-link work.
- Firecrawl: the 100,000-credit monthly plan size and the reserved floor for course-link work are now settings, changed with a reason.

## Bug / UI fixes

- Intake dates are read correctly across a year change and are not admitted again after a withdrawal.
- Fee figures that look implausible are held for a person, and a decided fee is not asked about again. This ships switched off.
- A provider description that was held is read again when the stored copy of the page changes.
- English requirements show where courses are still missing English, and repeat planning pauses for an onboarding that has stalled.
- Scholarship coverage states are clearer and retries are limited.

## Release and admission

New spend paths in this release ship switched off; turning one on is a separate recorded step. This note does not establish any gain in data, admission or publication. Human approval remains required, and the consumer API is unchanged.
