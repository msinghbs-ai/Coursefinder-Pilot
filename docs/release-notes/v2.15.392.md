# PIM Admin v2.15.392 — Layer 4 cards show their evidence; decisions show what actually happened

Date: 1 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Layer 4 Review cards:** each card shows:
  - its reference;
  - a link to the stored copy it rests on, with its capture date, and a note when a newer copy of that page exists;
  - a link to the course record.
- **After a decision:** the screen says what actually happened at the destination: admitted, applied, closed without admitting a value, queued, deferred, or saved but not yet visible.
  - For entry requirements it shows how many rows are active, excluded, superseded or waiting.
  - It shows the decision and audit numbers, so a saved decision can be checked before moving on.

## Bug fixes

None.
