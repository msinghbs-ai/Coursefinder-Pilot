# PIM Admin v2.15.353 — Courses with no page: recorded, not searched forever

Date: 25 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- Courses whose provider publishes no page for them, and conjoint degrees, are decided once per provider in Layer 4 and then leave the web search; any page found later brings them back.
- A provider whose courses are on another website can be given that course website.
- Firecrawl refusals are named ("target list refused", not "budget").
