# PIM Admin v2.15.395 — Guides state who acts, how alerts arrive and where the specialist tasks are

Date: 1 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Platform guide › Alerts:** alerts arrive by push and e-mail, sent by the hourly Work queue alerts task. Expect up to about 75 minutes from an issue to the message. The guide lists the rules (confirmation, cooldown, reminder, recovery, retries) with their settings. "Delivered" means the alert was sent, not that anyone read it: the person on call confirms receipt and a Platform Admin acknowledges the issue on Platform health.
- **Roles and SOPs:** the Pipeline Operator diagnoses, records and escalates. The PIM Admin paces, pauses, resumes and runs automations again; automations marked Platform Admin need the Platform Admin. Entry requirement items are decided by the Platform Admin only, with the choices Approve all rows, Approve except… and Reject the read.
- **SOP documents:** each one records its source commit, reviewed release and a content digest, so a copy can be checked for drift.
- **Platform guide › Specialist tasks:** each role's top tasks link to the specialist guide, with the lowest role, the source needed, what is saved and who to escalate to. Counsellors get wording for estimates, unstated grading scales and reporting a wrong value.

## Bug fixes

- The guide said alerts were planned through an e-mail service and shown on screen only; they have been sent by push and e-mail since 31 Oct.
- The operator SOP told the Pipeline Operator to pause automations and lower batch sizes, which the server allows only from the PIM Admin.
- Changing an automation without the role said "Platform Admin role required"; the server checks for the PIM Admin (and, for automations marked Platform Admin, the Platform Admin). The message now says so; who may change what is unchanged.
- Layer 4 Review: going Back from a university to an address of the same kind left the university's items on screen. The kind is shown again (found in the UR-09 acceptance walkthrough).
