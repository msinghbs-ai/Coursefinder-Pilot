# PIM Admin v2.16.16 — Invitations and password resets return to the admin sign-in; catalogue lists export to CSV

Date: 17 Nov 2026

Platform Admin, 16 Nov 2026 22:12 (overnight Admin UI task).

## What's new

- Administration › Users & roles: **Reset password** emails another person a link to choose a new password. It is not offered for a Platform Admin, your own account, the system account, a disabled account or an invitation not yet accepted.
- Administration › Users & roles › Create user › Send invitation: an optional **Full name**. The invitation email greets the person, names their role and links the Platform guide.
- Invitation and password reset links open the StudySearch Admin sign-in on the Cloudflare Worker. The person chooses their password first, then goes on to the workspace. The sign-in screen has **Forgot password?** for your own account.
- Providers, Courses, Locations, Scholarships and the Course readiness workspace: **Export CSV** › Export visible columns or Export all columns. The file holds every row of the filtered list (read page by page, with progress and Cancel), opens in Excel, and is named `<list>-<yyyy-mm-dd>.csv`.

## Bug / UI fixes

- An invited person was signed in by the invitation link but never asked to choose a password; they now set it on arrival.
- The website and Zoho APIs are unchanged (no database change in this release).
