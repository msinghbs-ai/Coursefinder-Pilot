# PIM Admin v2.15.405 — Intake year, start date and application deadline are kept

Date: 2 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Intake dates kept:** re-admission no longer clears an intake's year, start date or deadline.
- **Calendar reader:** keeps printed start dates and application-close dates, not just months.
- **Fill job (off):** fills empty years and start dates from the approved university calendar for courses whose page passes the course-page check. Off until switched on.

## Bug fixes

- Every re-admission cleared the intake year and start date.
- The calendar reader dropped printed days, years and application-close dates.
