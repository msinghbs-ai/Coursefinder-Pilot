# PIM Admin v2.15.369 — Search-document writer lock, Read again on the newest copy, long course pages read in slices

Date: 29 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Search documents:**
  - Every writer takes one writer lock, so a large change (such as a scholarship re-apply) and the scheduled search refresh no longer deadlock.
  - The scheduled refresh waits for its next run when another writer is busy.
- **Read again:**
  - It reads only the newest stored copy of a page.
  - The read on an older copy keeps its history, and its still-pending Layer 4 item is closed as superseded.
- **Academic entry requirements on a course page:**
  - A long page is read in slices that together cover the whole page; the sizes are settings.
  - A cut or unreadable slice holds the whole read instead of proposing part of it.
  - Every row keeps its quote on the page, and a row read twice is kept once.
- **Consumer API:** unchanged.
