# PIM Admin v2.15.356 — Layer 4 first runs: proven shapes admitted automatically

Date: 26 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- No-page and conjoint first runs are approved without a person when the provider's own course list is current and verified, at least 4 in 5 of the sample are confirmed not on it, and a person has already approved a provider whose list has the same shape.
- New list shapes still go to Layer 4, and one in ten that pass is kept for a person as an audit.
- Every automatic approval is listed in Decided as "Auto:" with its reason.
