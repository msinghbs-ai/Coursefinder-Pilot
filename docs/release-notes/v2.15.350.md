# PIM Admin v2.15.350 — Course page search: a daily cap and a per-course stop

Date: 24 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Course page search takes no more than 100 courses a day (Settings › Pipeline settings › Course search: courses a day). A person's running Find course pages task is counted but not held by it.
- A course with 6 different pages rejected as wrong is not searched again (Course search: stop a course after); the university-wide stop stays behind it.
- When the cap holds a task, the Task manager says "Today's course search cap is reached".
