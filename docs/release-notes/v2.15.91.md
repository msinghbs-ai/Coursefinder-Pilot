# PIM Admin v2.15.91 — Simpler menu and provider fee rules

Date: 25 Sep 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Jobs and Scheduled Tasks are one menu item, Jobs & Schedules, with two tabs.
- Approved provider fee rules settle fee frequency where a provider officially states what its fee means. First rule: UQ program pages show the indicative annual international fee.
- Fees admitted under a provider rule are recorded with the rule's wording.
- Each saved web page records which tool fetched it.
- Scheduled Tasks states that historical jobs are never reset or replayed.

## Bug / UI fixes

- Duplicate Layer 1 to 3 shortcuts removed from Scheduled Tasks.
- "Open Review Queue" on the Dashboard now reads "Open Layer 4".
- Remaining out-of-date automated tests fixed.
