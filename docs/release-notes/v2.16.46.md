# PIM Admin v2.16.46 — Course detail: shorter and role-aware

Date: 19 Nov 2026

Platform Admin, 18 Nov 2026 23:51.

## What's new

- Course detail: the Description pipeline is folded by default for Editors and Platform Admins; Counsellors and Viewers do not see it, nor Tasks that held this course.
- Course detail: Related insights & funding (QILT and PRISMS context) is folded by default for everyone.
- Course detail: scholarships are shown once, in the course's Scholarships section (three, then Show all (N) scholarships). The Provider detail keeps its own scholarship card.

## Bug / UI fixes

- Course detail: Check scholarships for this course and other task buttons are hidden for Counsellors and Viewers, and in Preview as Counsellor or Viewer.
