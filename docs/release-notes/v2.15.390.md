# PIM Admin v2.15.390 — Evidence address search and fee schedule approvals load again

Date: 1 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Evidence:** searching by a page address (https://…) now finds the stored copies whose address starts with it, in well under a second. Other searches are unchanged.

- **Waiting for approval (Adapter builder, central pages) and Fee schedules:** the list stopped with "The database took too long to answer". It now loads well within the time limit, with the same content.
- **Evidence search by source address:** the search stopped with the same message. It now returns the stored copies for that address.
