# PIM Admin v2.15.396 — One set of words for who changes and who admits

Date: 1 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Automations:** each automation shows who may change it and how its values get in (automatically while a switch is on, or by a person).
- **Budget gates:** each gate says who refuses (StudySearch or the provider), its mode, where the live value is and who changes it. In Observe mode a notice says nothing has stopped.
- **Platform health:** each check is marked as from this run, from an earlier run, or no result yet. No result is never shown as OK.
- **Retiring components:** the five retirement checks and the component's note are shown; removal without a named replacement needs an approved decision.
- **Guides and SOPs** use the same words throughout.

## Bug fixes

- The guide still gave the PIM Admin the retired priority queue, gave pause and run to the Pipeline Operator, pointed to retired screens, and said a person admits values that are admitted automatically while their switches are on.
- Two platform notices sent people to retired screens.
- The guide's Firecrawl figures were out of date; it now points to the live values.
