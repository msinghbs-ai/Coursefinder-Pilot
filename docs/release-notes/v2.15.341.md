# PIM Admin v2.15.341 — Plain error messages, a steady version, honest completeness

Date: 24 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- An error now shows as one plain line with a short reference; the full detail is kept for the Platform Admin. A message belongs to the screen that raised it and no longer follows you to the next screen.
- When a newer version has been released while this window was open, a notice offers a reload.
- Coverage › "Fully complete courses" counts the attributes the platform can read; the 20–24 Oct rows explain why they read 0.

## Fixes

- The official-page admission job had failed on every run since 23 Oct because a rule tried to apply a plain http:// course address; such an address now waits for a person and the job runs again.
- Raw database wording no longer appears in Platform health, Layer 2/3 or Scheduled jobs.
