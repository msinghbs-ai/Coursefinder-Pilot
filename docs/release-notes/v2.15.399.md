# PIM Admin v2.15.399 — Guides name the Pipeline Operator for Layer 4 decisions

Date: 2 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Layer 4 decisions:** the guide and the Operator SOP now say the Pipeline Operator decides Layer 4 › Inbox items (Course link, Held scholarship, Website needed). A Curator reads them and corrects the record. Entry requirement items stay with the Platform Admin.
- **Counsellor guide:** describes searching, reading and quoting what is held, and reporting a wrong value from Zoho.
- **SOP copies:** the Admin copy of the SOPs cannot be overwritten from an older source.

## Bug fixes

- The guide said a Curator decides Layer 4 items, but the system needs a Pipeline Operator or above.
- The Counsellor guide mentioned shortlists, which do not exist.
