# PIM Admin v2.15.361 — Academic entry requirements: course reading, resolution and admin views

Date: 28 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Provider drawer › Academic entry requirements:** the provider's published entry rows. Filter by country, level and status (50 rows a page). Each row shows its quote, source, stored copy, as-at date and the read that produced it.
- **Course detail › Academic entry requirements:**
  - the course's own requirement rows: a minimum score with its printed basis, prerequisites and selection tasks;
  - the requirement that applies to a student from a chosen country. It is worked out in a fixed order: course rule, course row for the country, course band, provider minimum, otherwise "contact the provider". A qualification the provider considers case by case is shown as case by case.
- **Platform Admin:** read one course's entry requirements from its stored page. The rows wait in Layer 4 (Course entry first read) until a person admits them.
- Consumer API unchanged.
