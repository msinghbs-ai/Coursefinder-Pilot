# PIM Admin v2.15.83 — Layer 4 review desk

Date: 24 Sep 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Layer 4 is a review desk: a queue and one decision at a time, oldest first; the next item opens after each decision.
- Each item shows the course and provider by name, the reason, what is recorded now, what the AI suggested and the exact words on the page.
- A rule-based suggestion (Reject, Approve or Check) is shown and never applied automatically.
- Links to the provider page, the course page and a ready-made web search.
- The decision note is pre-filled from the suggestion.
- Less common actions are under More; technical detail is collapsed.
- Status and task filters are remembered; status cards show waiting items, the oldest item against the 7-day target, and suggestion counts.

## Bug / UI fixes

- The Evidence screen no longer times out and shows no items.
- Developer-facing review reasons are replaced with plain instructions.
- Page quotes no longer show web-link formatting.
