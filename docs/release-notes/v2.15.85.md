# PIM Admin v2.15.85 — Layer 4 batches

Date: 24 Sep 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Layer 4 Batches view: repeat cases grouped by task and suggestion.
- Preview before deciding: every item with its page quote, untick any, one reason, typed confirmation (for example "REJECT 41").
- Every item in a batch is recorded as if decided on its own, plus a batch record; if any item fails, none are decided.
- Applying a batch needs the Pipeline Operator role; curators can preview.
- Scholarship scope items show scholarship and provider names; scholarship scope batches and history are in the Batches view.

## Bug / UI fixes

- Approve is no longer offered for scholarship scope items.
- Scholarship cohort reasons are shown in plain English.
- The batch panel no longer inserts itself into the page.
