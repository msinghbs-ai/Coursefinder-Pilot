# PIM Admin v2.15.94 — Clearer operations screens

Date: 26 Sep 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Each Layer screen shows its title once; the Layer header is a slim bar with its purpose and refresh button.
- Jobs shows only columns that have values, one "Completed" status, and fits the screen.
- Layer 4: the queue scrolls in its own column and the decision panel stays in view; batch history loads details only when opened.
- Layer 3 states plainly when AI interpretation is paused and why.
- More UQ fees admitted by the approved provider rule; each course keeps one current tuition fee.

## Bug / UI fixes

- Developer labels replaced with plain titles.
- The "Suggested reject" card no longer implies every rejection is about fees.
