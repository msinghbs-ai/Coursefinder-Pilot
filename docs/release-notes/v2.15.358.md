# PIM Admin v2.15.358 — CRICOS end dates: deregistered providers told apart from current ones

Date: 26 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- Every CRICOS course registration that is no longer on the latest register edition now carries an end date (the last date the register listed it).
- A provider none of whose courses is on the register is marked as having ended its CRICOS registration; one that comes back is restored. A safety check stops this when a register file looks incomplete.
- A new daily job keeps these dates current after each register edition. Course retirement is unchanged and stays a Platform Admin approval.
