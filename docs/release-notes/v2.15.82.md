# PIM Admin v2.15.82 — Layer 4 review clarity & remembered filters

Date: 23 Sep 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Layer 4 shows the plain-English reason on every review item.
- Layer 4 remembers each reviewer's status and field filters between visits, with a Reset filters button.
- Layer 4 status filter uses plain labels and adds "All statuses".
- Layer 4 review detail summarises the automatic checks; technical data is under "Technical detail".
- Common screen parts now come from one shared set for consistency.

## Bug / UI fixes

- Fewer loading errors at busy times: admission refreshes only the courses it changes.
- Layer 4 lists up to 250 items, so older waiting items no longer drop off.
- Catalogue filters and search are remembered exactly as before.
