# PIM Admin v2.15.393 — Retired jobs cannot be switched back on; changed migrations are refused

Date: 1 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Scheduled jobs:** a job that is being retired or has been retired shows as **Retiring** or **Retired**, with what replaced it and when it will be removed.
  - It has no Resume, run or schedule controls.
  - **Resume area** leaves it off.
  - Its history stays visible.
- **Deployment:** a database change that has already been applied is skipped only when it is unchanged. A changed one is refused before anything runs.

None.
