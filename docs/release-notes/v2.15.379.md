# PIM Admin v2.15.379 — Remediation hold for course-page corrections

Date: 31 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Remediation hold (StudySearch SS-007):** a course whose course page is being corrected can be held.
  - **While held:** no automatic job searches for a new page, binds one, reads one or sends the course to AI matching, so nothing is spent on it until a person decides.
  - **How it is enforced:** through controls that already exist: the binding guard, the one search stop gate, AI match preparation and the link search send path.
- **The correction (Platform Admin only):** one university at a time, with an exact expected count. Every binding is checked again before it changes; the before state is recorded and each course can be restored.
  - The binding stops being the course page; its evidence and identity are kept.
  - The wrong official link is set to "unverified" (an existing status), and search is asked to refresh.
- **This release changes no data:** no course is held and no page or link is changed. The correction runs only on the Platform Admin's approval.
- **Consumer API:** unchanged.
