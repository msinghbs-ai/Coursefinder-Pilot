# PIM Admin v2.15.368 — Course evidence values in words; country selector fits a phone

Date: 29 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Course detail › Evidence and history:**
  - A field fill whose value is a record, such as an entry requirement read, is told in words (for example "4 rows for review, 2 not kept").
  - It no longer shows "[object Object]".
  - Cross-check values are shown the same way.
- **Course detail on a phone:** the Country of prior education selector stays inside its card.
- **Operator tools:**
  - The read-only Entry requirements tour also checks DP020 Course detail at desktop and phone width: country order, India result, scholarships and the evidence overlay.
  - The tour closes the phone row drawer.
  - A read-only deployed acceptance check runs the same on deploy.
- **Consumer API:** unchanged.
