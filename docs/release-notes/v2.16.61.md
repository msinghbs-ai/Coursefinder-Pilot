# PIM Admin v2.16.61 — Completeness bars, Missing field pills, provider bulk bar and provenance panel; security headers and CI gates

Date: 20 Nov 2026

Find the incomplete records in one click, see where a value came from, and a tighter security baseline.

## What's new

- Catalogue › Courses and Providers: a Completeness bar on every row. Courses draw the existing six-signal score (registration, structure, fee, intake, English, description); Providers show the share of nine tracked fields held. The bar is a progress bar with the percentage as its label, with no colour bands.
- Catalogue › Courses and Providers: a Missing field pill bar. Courses: Fee, Intake, English, Scholarship, Description and Study load narrow the list on the server through filters the list already had. Providers: the nine tracked fields (description, website, city, state or region, type, phone, email, address, established year); several pills keep providers that lack every field chosen, and Export CSV, total and rows agree.
- Catalogue › Providers: tick providers to get a bulk bar with Fill fields (description only), Export selected (CSV, with each provider's completeness and missing fields) and Clear.
- Catalogue › Providers detail drawer: a Completeness and provenance panel showing the nine fields as Held or Missing and the description's source as Register, AI verified or Human input · Locked. Other fields do not record their source per field yet, and the panel says so.
- Guides: the Counsellor, Curator and Platform Admin role guides (version 1.1) and the Courses and Providers page guides describe completeness, Missing field pills, the bulk bar and provenance, Intake Run & Validate and Layer 1 country preparation.
- Security: the Cloudflare Worker now sends a Content-Security-Policy, Strict-Transport-Security, X-Frame-Options DENY, X-Content-Type-Options nosniff, Referrer-Policy and Permissions-Policy. Page text read from a site is fenced as untrusted, with hidden markup removed, before any model sees it. Website API v3 no longer forwards any database message to the caller. Pull requests run a secret scan, a dependency audit and a CycloneDX SBOM.
