# PIM Admin v2.15.359 — Hotfix: one identity check for every fee write

Date: 26 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Bug fixes

- An international fee is now checked against the country's accepted course-page proofs at the moment it is stored, whichever part of the platform wrote it. A fee that fails is kept for review, not shown.
- The university adapter checks the fee's proof before replacing a course's current fee.
