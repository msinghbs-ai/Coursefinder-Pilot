# v2.15.482 — Intake dates: fair turns, current calendars, course evidence

Platform Admin direction 5 Nov 2026 15:50 (UNSW blockage and cross-university fairness); P0 IQ-00313.

## What changes

- Every university with eligible intake rows gets a turn in each hourly run (25 rows a university a round; a setting). The batch size is unchanged.
- Old calendar editions no longer supply period names or dates; Term 1 and Teaching period T1 are one period.
- A date is admitted only with course-specific evidence that the course offers the intake, and a month-only match needs the course to follow the university's main calendar.
- Admitted intake values can be withdrawn by the Platform Admin with a reason, keeping the history and holding the course's intakes with the existing lock.

## Not changed

The consumer API (Website API v2, Zoho) is unchanged. No new job, scheduler or screen. Unique-month matching remains switched off until it is validated in production.
