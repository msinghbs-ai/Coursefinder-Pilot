# PIM Admin v2.15.343 — Hotfix 2: a person's course page search spends its credits

Date: 24 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Task manager: a Find course pages task that is sent to the search but whose credits are refused says so (Blocked: credits refused, and why) instead of looking alive.

## Fixes

- Find course pages started by a person at a university whose automatic search had stopped was handed to the search, but every credit was refused, so nothing was searched. The credit check now lets a person's task through, as the search queue does. Budgets and the target-only rule still apply.
