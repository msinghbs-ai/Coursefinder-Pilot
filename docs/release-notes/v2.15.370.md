# PIM Admin v2.15.370 — Enrichment reliability and AI answer limits

Date: 30 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Course source finder:**
  - Choosing the next universities is worked out once per set, so it finishes well inside the database time limit. It was timing out under load.
  - The same universities are chosen, in the same order.
- **Course page reads:** a page is claimed by exactly one read call, so the two reading jobs no longer fetch and pay for the same page twice.
- **University onboarding:** each onboarding step follows its own university's job.
- **Adapter builder:** a sample capture and a proposal are counted in the worker ledger with their failures.
- **AI reads:**
  - Every reader's answer length is a setting (Settings › Pipeline settings › AI answer limits), defaulting to the values used before.
  - An answer cut at its limit holds the whole read.
  - The cost of every call is recorded, including when a read fails.
- **Consumer API:** unchanged.
