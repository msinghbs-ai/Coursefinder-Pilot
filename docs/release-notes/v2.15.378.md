# PIM Admin v2.15.378 — Rule 4 paused on purpose

Date: 31 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Rule 4, "low agreement, page wins" (daily job):** paused by the Platform Admin until the rule is reviewed.
  - **What it does:** it admits a field from the provider's page when a university adapter reads the field often but agrees with held values less than 90% of the time.
  - **Why it is paused:** it had failed every day since 29 October, and restarting it would restart those automatic admissions.
  - Its description in the job list now says what it does and that it is paused.
- **Consumer API:** unchanged.

## Fixes

- **Error reporter:** it could be called without signing in, although it refused such calls. That permission is removed; nothing changes for users.
