# PIM Admin v2.15.367 — Entry requirement reader: quotes read with their table structure

Date: 29 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Academic entry requirements reader (worker v0.52.0):**
  - A printed cell quoted together with the structure that names it counts as on the page: a table's header line with one of its rows, or a PDF row's first cell with one other cell of that row.
  - A band written with its column header's words (for example "ATAR 70") is the printed cell only when the whole row is quoted.
  - A table with no header row carries the label printed just above it.
  - A quote never crosses into the next labelled row, so one country's table cannot prove another's.
- **Gates:** quote on the page, scale, identity, completeness and whole-run admission are unchanged.
- **Re-reads:** Federation, Wollongong, Otago Polytechnic and UWA are read once again through Read again; their earlier incomplete items stay unapproved.
- **Consumer API:** unchanged.
