# PIM Admin v2.16.53 — Layer 4 Review › Grid filters by country and provider type

Date: 19 Nov 2026

Platform Admin, 19 Nov 2026 16:18 (chat S1-RM-Design, s766 and s767).

## What's new

- Layer 4 Review › Grid has Country pills (All, Australia, New Zealand, Canada) and Provider type pills (All, University, VET / College, School, HEI) beside the kind and reason filters. The rows, the count and Export CSV follow them. University covers university, university college and wānanga; VET / College covers TAFE / polytechnic and private VET. The pills are not kept in a saved view.
- Provider descriptions: a university that shares a website host with a pathway college, or with a second registration of itself, is now decided by a recorded host owner (Victoria University, RMIT University and Western Sydney University). A recorded trading name (Torrens University, Moore Theological College) counts as an identity name for the page proof, and one stored-page read is queued for each of the two.
