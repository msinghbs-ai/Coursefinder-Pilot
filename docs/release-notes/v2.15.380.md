# PIM Admin v2.15.380 — Fill the gaps skips courses with a wrong page

Date: 31 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Fill the gaps (StudySearch D5a):** a course whose page is known to be another course's (a mismatch) is held out of the standing queue until a correct page is found.
  - **Why:** in the four days to 31 October, 11,332 such tries ended "no correct course page", and none filled a field.
  - **Resuming:** when a page is found, the course is queued again by itself.
- **Consumer API:** unchanged.
