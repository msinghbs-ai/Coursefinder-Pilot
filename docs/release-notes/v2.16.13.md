# PIM Admin v2.16.13 — Course descriptions: earlier readings the platform set aside no longer count as a person's refusal

Date: 16 Nov 2026

Platform Admin, 16 Nov 2026 11:32: only genuine human decisions count as an earlier refusal of a course description.

## What's new

- The course description machine rule is now version cdesc-machine-v2: every first description waiting in Layer 4 is checked again under it.

## Bug / UI fixes

- Course descriptions waiting in Layer 4 were held as "a person decided against an earlier description for this course" when the earlier description had only been set aside by the platform (for example when the new description prompt was released on 15 Nov). Only a person's decision now counts. The waiting descriptions are checked again against every other check (copied sentences, the course's identity, wording, figures, duplicates, evidence age), and those that pass are admitted as before; the rest stay for a person.
- With fewer descriptions waiting, new course description readings start again (they pause while 1,500 wait for a person).
- The website and Zoho APIs are unchanged (checked against their baseline before and after the change).
