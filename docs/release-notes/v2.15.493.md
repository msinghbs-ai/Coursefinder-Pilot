# PIM Admin v2.15.493 — English course groups and a clear next step

Date: 6 Nov 2026

## What's new

- Coverage > Attributes > English policies shows faculty and course-group scores. A Platform Admin approves the policy and saves group bindings to fields of education (ASCED codes), course-title patterns or both, with a reason. A group cannot supply courses before both steps.
- No rule yet shows each provider's stage, why no rule is available, courses missing English, the next try and recent jobs. Run now reads the stored English pages again without fetching pages or using credits.
- Own course readings, named-course rules, manual locks and held cases keep their precedence. Courses reached by groups with different scores are held for a person. Search for new non-university English pages ships switched off.

## Bug / UI fixes

- Reading a policy again with the same parser keeps the group bindings saved by a person.
- Group-policy approval closes waiting group policies only; default-policy approval closes waiting default policies only.
- English fixture execution propagates producer and SQL failures. PostgreSQL must emit every required scenario assertion before the fixture can pass.
