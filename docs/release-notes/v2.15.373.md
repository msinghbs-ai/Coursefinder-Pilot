# PIM Admin v2.15.373 — Cached snapshots for the slow admin screens

Date: 30 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Completeness › Courses and Attributes:** coverage totals are read from a snapshot that job course-coverage-snapshot rebuilds after each hourly build. The screen shows when it was built and marks it Stale after a setting. Drill-downs stay live.
- **Pipeline jobs, Courses and Providers lists:** the page is chosen first and the per-row figures are worked out for that page only. The rows, order and fields are the same.
- **Toolset notices, scholarship publishability and field coverage by country:** read from snapshots that job admin-read-snapshots rebuilds on settings (Pipeline settings › Platform upkeep). Each shows its time and age and a Stale mark. A person's fix (Search again, a website entered, a publication batch) rebuilds the snapshot within a minute. One university's field coverage is always read live.
- **Platform health › Why values are missing:** shows when its last run actually started and finished, marked Stale after 75 minutes (a setting).
- **Permissions:** unchanged. Nothing is admitted or published differently.
- **Consumer API:** unchanged.
