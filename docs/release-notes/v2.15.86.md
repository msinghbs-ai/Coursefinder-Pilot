# PIM Admin v2.15.86 — Layer 4 team working

Date: 24 Sep 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Opening an item reserves it for you; a reservation lapses after 30 minutes without activity.
- Items someone else is reviewing are marked "In review" and show who has them.
- Queue filter: All, Mine or Unassigned.
- Keyboard keys: R reject, A approve, E edit, N next item.
- Edit and approve for tuition fees uses a form.
- Batches refuse items someone else is reviewing.

## Bug / UI fixes

- The scholarship tools in the Batches view start collapsed.
