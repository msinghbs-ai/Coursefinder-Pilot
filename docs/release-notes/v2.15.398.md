# PIM Admin v2.15.398 — Using a reviewer's course page replaces the old one

Date: 1 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Layer 4 Review, course links:** Use the new page makes the approved page the course's one official page. The old page is retired and the course record shows the new page.
- **Pages set by hand:** if a person set the course page on the course record, Layer 4 refuses the change and points to the course record.

## Bug fixes

- Use the new page added the new page but left the old one active, so a course could show two official pages.
- On a course with a page set by hand, the decision was recorded as approved although nothing changed.
