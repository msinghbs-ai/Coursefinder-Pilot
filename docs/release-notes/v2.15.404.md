# PIM Admin v2.15.404 — Spending limits enforced on every path; alert watchdog

Date: 2 Nov 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **AI spending:** every paid AI lane checks one rule before claiming work (credit floor, US$14 daily total, lane limit). It refuses only in Stop mode, which stays off until the Platform Admin switches it.
- **AI spend counting:** each cost is counted once.
- **Firecrawl:** the monthly limit is checked on every reading path, including on-demand runs and adapter captures.
- **Watchdog:** an hourly external check that the health and alert jobs are running.
- **Backup label:** the settings backup says it holds settings only.

## Bug fixes

- Course matching and the Adapter builder could spend on AI with no limit check.
- Some AI costs were counted twice and scholarship re-check costs were not counted.
- Adapter page captures and on-demand runs could read past the monthly Firecrawl limit.
