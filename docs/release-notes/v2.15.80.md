# PIM Admin v2.15.80 — Automated tuition admission & navigation clean-up

Date: 23 Sep 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Layer 3 now checks Layer 2 tuition fees automatically on a schedule. Confirmed fees are recorded in the catalogue and appear in search and the website API.
- Administration > Environment migration: Activate and Pause for Layer 3 AI profiles, each with its own required reason and an audit trail.
- Layer 3 - AI Interpretation shows live queue status.
- Platform Admins can open the OpenRouter API Key form from any screen.
- Layer 4 review items explain in plain English what happened and what to check.
- Fees held back at admission now appear in Layer 4.
- Navigation: Quality & Insights groups Completeness, Statistics & Rankings and Compare. Review Queue is retired; old links open Layer 4.
- Website API: course search and scholarship search.

## Bug / UI fixes

- Dashboard Open reviews links now open Layer 4, not an empty retired queue.
- Profile activation no longer records a pre-filled reason.
- The OpenRouter card no longer overlaps the card beside it.
- One failed item no longer stops a whole Layer 3 batch.
- A course total, or a fee marked only "indicative", is no longer treated as an annual fee.
- A fee year is only accepted when the page shows it next to the amount.
