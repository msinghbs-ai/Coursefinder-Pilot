# PIM Admin v2.15.372 — Entry requirements review path

Date: 30 Oct 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## Changes

- **Layer 4 › Inbox, entry-requirement (AER) items:**
  - They show as their own kind, with every row, its quote, the source and the stored copy.
  - The Platform Admin can Approve all rows, Approve except (tick the rows to leave out, with one reason) or Reject the read.
  - Excluded rows stay visible, marked "excluded by approve except" with the item and reviewer named. They are never admitted, superseded or re-read automatically.
- **One item at a time:** bulk and batch decisions skip entry-requirement items and say how many they skipped.
- **Who decides:** only the Platform Admin admits or rejects these items. Curators can read them, and keep their editing in Catalogue › Entry requirements.
- **Bulk Read again** reads only the newest stored copy of each source. Older copies keep their history, and their waiting items are closed as superseded.
- **Consumer API:** unchanged.

## Fixes

- The bulk Read again role check never applied inside its function, so any signed-in user could call it. It now requires the Platform Admin.
