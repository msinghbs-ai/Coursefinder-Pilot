# CF-093 Security boundary

- Preserve public/admin governed RPC routing.
- Do not expose service-role keys, provider credentials or private Evidence.
- Rank checks remain server-side.
- Target scope options must be server-authorised.
- Layer 3 execution remains Evidence/profile/model/revalidation governed.
- Layer 4 remains auditable exception resolution.
- Search/Publication are not implicit consequences of ingestion.
