# PIM Admin v2.15.89 — Layer 4 decision forms for every category

Date: 24 Sep 2026
State: release candidate (v2.15.79 remains the accepted recovery release)

## What's new

- Official course link items have a form: paste the provider's course page link, then approve. It appears in search.
- Scholarship scope items show how many courses still need a decision, open them in batch work, and can be marked as done once decided.
- Reviewer-entered links are recorded against a dedicated "Layer 4 human review" source.

## Bug / UI fixes

- Official course link items could not be approved.
- Scholarship scope items could not be completed.
- Five out-of-date automated tests fixed or retired.
